# Digital Art Space

A gallery website that showcases digital artworks,
with artist profiles and contact links.

Final project for Web Design course in Semester 3.

**Live site:** https://digital-art-space-project.vercel.app

## Features
- Hero slideshow
- Filterable artwork gallery with detail pop-ups
- Artist profiles linked to their works
- Contact dialogs
- Responsive layout for phones and desktops

## Built with
HTML, CSS, and JavaScript

## Run it locally
Open `index.html` in a browser or use VS Code's Live Server.
